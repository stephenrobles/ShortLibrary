ShortLibrary 1.0

  • Reads your whole Shortcuts library and shows it as the same tiles Shortcuts draws, in Shortcuts' own order.
  • Nested folders, nested tags, favorites, notes and smart lists, all without touching the Shortcuts app.
  • Sort by name, date added, last modified, last run, action count or run count; search names, tags and notes.
  • Run shortcuts in the background from the grid, with input when a shortcut accepts it.
  • App icons for app-based shortcuts once you link the Shortcuts folder; real creation and modified dates too.
  • Organization syncs through your iCloud to the iPhone, iPad and Vision Pro companion.
